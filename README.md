# BlinkIT Grocery Sales Dashboard

I created this Power BI dashboard to explore grocery sales data and compare results across products and outlets.

## What I did

- Cleaned the `Item Fat Content` column in Power Query by combining inconsistent labels such as `LF` and `low fat` into `Low Fat`.
- Created measures for total sales, average sales, average rating, item records, and average item visibility.
- Built charts to compare sales by item type, outlet type, outlet size, outlet location, and fat content.
- Added slicers for outlet location, outlet size, and item type so users can filter the report.
- Created a table to compare sales and other measures across outlet types.

## Tools

- Power BI Desktop
- Power Query
- DAX

## Note

The dataset doesn’t include transaction dates, so the report compares products and outlets rather than showing sales over time.
